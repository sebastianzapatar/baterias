02 Conceptos clave

El sistema estudiado

Un usuario industrial en Colombia con demanda de 158.742,57 MWh/año (pico de 23,23 MW) se abastece de la red y, según la etapa, de un campo solar (PV), una batería (BESS) y cuatro unidades a gas (G1–G4, 25,2 MW disponibles). Se simulan las 8.760 horas de 2025 y se evalúa a 20 años con WACC de 10 %.

02 Conceptos clave

Glosario mínimo

PV · BESS
Campo solar (MWp DC) y batería (MW de potencia, MWh de energía).
SOC · EFC
Estado de carga [MWh] y ciclos equivalentes completos, que miden el desgaste por uso.
Reglas A, B, D
A: autoconsumo. B: mérito diario (horas más caras). D: como B, con exportación.
Reglas C, F
Reglas de mercado orientadas al precio de bolsa; se comparan por separado.
Sufijo _INT
Versión de la regla integrada con la flota térmica (Etapas II y III).
OPT_*
Benchmarks con previsión perfecta (MILP). Cotas de referencia, no reglas operables.
T0 · T1
T0: tarifa regulada N3 casi plana. T1: tarifa indexada al precio de bolsa 2025.
K1–K4 · M01–M12
Configuraciones de referencia (K3 es la principal) y malla de doce tamaños de la Etapa III.
VPN · ΔVPN
Valor presente neto a 20 años; el ΔVPN compara con batería frente al mismo PV sin batería.
VPN ajustado
VPN financiero más el valor de las emisiones evitadas al precio de carbono elegido. No es caja.
H_B4 · H_B3
Dos hipótesis de CAPEX local de la batería; H_B4 es la base.
03 Ambiente virtual · una sola vez

Pasos 1 y 2: Python y la terminal

Un ambiente virtual (.venv) es una carpeta con su propio Python y las versiones exactas de requirements.txt, sin alterar otras instalaciones. Se crea una vez; después solo se activa.

1 · Instalar Python 3.12 o superior

Descargue el instalador de python.org/downloads. En la primera pantalla marque Add python.exe to PATH y luego Install Now.

py --version

Si tiene varias versiones, py --list las muestra todas.

Descargue el instalador para macOS de python.org/downloads y ejecútelo.

python3 --version

Verificado con Python 3.12.13 en macOS y 3.14.5 en Windows.

2 · Abrir una terminal dentro de la carpeta de entrega

Abra la carpeta de entrega (baterias-main o baterias) en el Explorador, clic derecho en un espacio vacío y Abrir en Terminal. También puede escribir powershell en la barra de direcciones y pulsar Enter.

Abra Terminal, escriba cd y un espacio, arrastre la carpeta de entrega (baterias-main o baterias) desde el Finder a la ventana y pulse Enter.

Para confirmar, dirls debe listar requirements.txt y los cuadernos.

03 Ambiente virtual · una sola vez

Pasos 3 a 5: crear, activar e instalar

Crear el ambiente 
py -3.12 -m venv .venv
python3 -m venv .venv

Con otra versión, cambie -3.12 por la suya (p. ej. -3.14) o use py -m venv .venv.

La carpeta .venv puede quedar oculta en el Finder porque empieza con punto.

Activarlo: la terminal debe empezar con (.venv) 
.venv\Scripts\Activate.ps1
.venv\Scripts\activate.bat
source .venv/bin/activate
Instalar las librerías (cientos de MB; varios minutos) 
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Si PowerShell bloquea la activación

Mensaje «la ejecución de scripts está deshabilitada». Ejecute una vez, responda S y vuelva a activar:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Solo afecta al usuario actual. Alternativa: cmd con activate.bat.

matplotlib · seabornFiguras

pvlibGeneración solar horaria
pypsa · highspyDespachos óptimos (HiGHS)

03 Ambiente virtual · una sola vez

Pasos 6 a 8: verificar y abrir JupyterLab

Verificar la instalación: debe imprimir Ambiente listo 
python --version
python -c "import numpy, pandas, matplotlib, pvlib, pypsa, highspy; print('Ambiente listo')"
Registrar el kernel (recomendado): aparecerá como Python (PV-BESS) 
python -m ipykernel install --user --name pv-bess --display-name "Python (PV-BESS)"
Abrir JupyterLab con el ambiente activado y en la carpeta de entrega 
jupyter lab

La terminal debe quedar abierta. Para terminar, cierre la pestaña y pulse Ctrl+C.

La regla más importante

Todos los cuadernos buscan sus datos a partir de la carpeta desde la que se abrió Jupyter. Si se abre desde otra carpeta, fallan con FileNotFoundError.

Solución: cierre Jupyter, abra la terminal en la carpeta de entrega, active el ambiente y vuelva a ejecutar jupyter lab.

Rehacer el ambiente desde cero

Si la instalación quedó incompleta o cambió la versión de Python, borre .venv y repita los pasos 3 a 7. No afecta cuadernos ni datos.

Remove-Item -Recurse -Force .venv
rm -rf .venv

Aceleración opcional del cuaderno 15

Numba baja el 15 de unos 5 a unos 2 minutos, con el mismo resultado. Se instala aparte para no cambiar NumPy; el cuaderno la detecta solo.

python -m pip install --no-deps --target .venv\numba -r requirements-vpn.txt
python -m pip install --no-deps --target .venv/numba -r requirements-vpn.txt

¿Tiene Anaconda o Miniconda?

Cree igualmente el ambiente con venv a partir del Python de python.org. Mezclar paquetes de conda y pip en el mismo ambiente puede producir versiones distintas de las fijadas.

04 Ejecutar un cuaderno

Ejecutar todo un cuaderno en JupyterLab

Abra el cuaderno con doble clic en el explorador de la izquierda.
Compruebe el kernel arriba a la derecha; debe ser el del ambiente, p. ej. Python (PV-BESS).
Kernel → Restart Kernel and Run All Cells. Reiniciar garantiza que no queden variables de una corrida anterior.
Espere a que todas las celdas muestren un número y el indicador del kernel quede vacío.
Revise que no haya recuadros rojos de error y compare con las cifras de control.
Guarde con Ctrl+S si quiere conservar las salidas.

La interfaz en un minuto

  • Cada cuaderno es una lista de celdas: las de texto explican y las de código calculan.
  • [ ] sin ejecutar · [*] ejecutándose · [12] terminada.
  • Un círculo junto al kernel se rellena mientras está ocupado.

Otras acciones útiles

  • Kernel → Interrupt Kernel detiene una ejecución.
  • Shift+Enter ejecuta una sola celda.
  • File → Save and Export Notebook As → HTML genera una copia para quien no tenga Python.
04 Ejecutar un cuaderno

Otras formas: VS Code y la terminal

Con Visual Studio Code

Instale las extensiones Python y Jupyter de Microsoft.
Abra la carpeta de entrega con File → Open Folder.
En Select Kernel elija .venv o Python (PV-BESS).
Pulse Run All. VS Code ejecuta desde la carpeta abierta: se cumple la regla de la carpeta raíz.

Desde la terminal, sin navegador

Útil para ejecutar varios seguidos; el resultado queda guardado dentro del cuaderno.

jupyter nbconvert --to notebook --execute --inplace 14_Comparacion_anual_reglas_integradas.ipynb
  • Para el 02 añada --ExecutePreprocessor.timeout=-1.
  • Los nombres con espacios van entre comillas: "01_Modelo base PV_BESS.ipynb".
  • Para una copia en HTML cambie --to notebook --inplace por --to html.

Ejecutar sobrescribe figuras y algunas tablas de salida. Los datos de entrada y los resultados ya calculados no se modifican. Si una corrida anterior importa, copie antes sus carpetas de salida.

06 Cambiar los datos de entrada

Cómo cambiar cada dato

Demanda · datos/load variable.csv

  • Edite con un editor de texto o pegue la serie en la columna Porvenir.
  • 8.760 filas, día antes que el mes, MW sin negativos y con punto decimal (22.84).
  • Excel en español guarda coma decimal: desmarque Usar separadores del sistema antes de guardar y verifique en el Bloc de notas.
  • Las horas en 0 MW se tratan como cortes de medidor y se imputan con la mediana (±7 días).

Precio de bolsa · .xlsx

  • Pegue el reporte de XM de otro periodo con la misma disposición: una fila por día, horas 0 a 23.
  • Conserve las dos filas de título y los encabezados en la fila 3. Fechas de 2025.
  • Los encabezados 0 a 23 deben quedar como texto; si los escribe, use '0, '1… (diapositiva 18).
  • Guarde como .xlsx con el mismo nombre y cierre Excel. T1 se recalibra sola.

Sitio o recurso solar · TMY

  • Región incluida: cambie sitio = 'Oriente' (01, secc. 3) y REGION_SOLAR = 'Oriente' (02, secc. 2). Opciones: Caribe, Antioquia, Suroccidente, Oriente, Nordeste.
  • Sitio nuevo: descargue el TMY horario del visor de NSRDB y reemplace uno de los cinco archivos de datos/ conservando el nombre.

Costos de inversión · datos/CurvasCapexPVBESS.xlsx

  • Parametros_PV: C6–C15, C18, C20, C33–C34 (no edite C16 ni C17, son fórmulas).
  • Parametros_BESS: filas 5 a 8, columnas D a J. Suministro_BESS: A13 y B13. Trayectorias: D8 y G8.
  • No todas las celdas amarillas cuentan y hay que guardar desde Excel o LibreOffice (diapositiva 19).
  • No inserte ni borre filas o columnas. El OPEX se deriva del CAPEX (2 % PV, 1,5 % BESS).

Qué buscar en los resultados

Cuadernos 08 · 09

Etapa I · sin térmica
